# دليل استخدام وتطوير النظام المحاسبي المتكامل (الإصدار المحدث)

هذا الدليل يقدم إرشادات شاملة حول كيفية تشغيل النظام المحاسبي المتكامل، وتعديل الكود الخاص به، بالإضافة إلى أفضل الممارسات لرفعه على GitHub لضمان استدامته وتطويره المستقبلي.

## 1. نظرة عامة على المشروع

النظام المحاسبي المتكامل هو تطبيق ويب بسيط يعتمد على HTML، CSS، و JavaScript. يوفر هذا النظام الوظائف الأساسية التالية:

*   **لوحة التحكم**: عرض ملخص سريع للبيانات.
*   **إدارة المنتجات والمخزون**: واجهة لإدارة المنتجات وتتبع المخزون، مع قائمة منتجات مستوردة من قائمة Lucca Caffè Italiano.
*   **نظام الفواتير المتقدم**: إنشاء، عرض، وإدارة الفواتير مع حسابات الضرائب والخصومات (يستخدم التخزين المحلي للمتصفح).
*   **إدارة الطاولات**: نظام لإدارة حالة الطاولات وسعتها (مثالي للمطاعم/المقاهي، يستخدم التخزين المحلي).
*   **نظام المصادقة**: تسجيل الدخول والخروج (وهمي، يستخدم التخزين المحلي).

**ملاحظة**: يعتمد هذا المشروع بشكل كبير على التخزين المحلي للمتصفح (`localStorage`) لحفظ البيانات. هذا يعني أن البيانات ستكون متاحة فقط على الجهاز والمتصفح الذي تم إدخالها فيه، وستفقد إذا تم مسح بيانات المتصفح. للاستخدام الفعلي، يوصى بربطه بقاعدة بيانات حقيقية.

## 2. هيكل المشروع

يتكون المشروع من الملفات التالية:

```
accounting_system/
├── index.html         # الواجهة الرئيسية للتطبيق
├── style.css          # ملف التنسيقات (CSS)
├── auth.js            # منطق نظام تسجيل الدخول والمصادقة
├── invoice.js         # منطق نظام الفواتير المتقدم (مع الضرائب والخصومات)
├── tables.js          # منطق نظام إدارة الطاولات
├── products.js        # منطق نظام إدارة المنتجات والمخزون
├── lucca_products.json # ملف JSON يحتوي على قائمة منتجات Lucca Caffè Italiano
├── app.js             # ملف JavaScript الرئيسي للوظائف العامة والتنقل
└── README.md          # هذا الدليل
└── todo.md            # قائمة المهام المكتملة والمستقبلية
```

## 3. كيفية تشغيل المشروع على جهازك المحلي

لتشغيل هذا المشروع، لا تحتاج إلى خادم ويب معقد. يمكنك فتحه مباشرة في متصفح الويب الخاص بك:

1.  **تنزيل الملفات**: قم بتنزيل جميع ملفات المشروع (المجلد `accounting_system`).
2.  **فتح `index.html`**: ابحث عن ملف `index.html` داخل المجلد الذي قمت بتنزيله.
3.  **افتحه بالمتصفح**: انقر نقراً مزدوجاً على ملف `index.html`، أو اسحبه وأفلته في نافذة متصفح الويب (مثل Chrome, Firefox, Edge). سيتم فتح التطبيق مباشرة.

**ملاحظة**: إذا كنت تخطط لتطوير المشروع بشكل أكبر، قد ترغب في استخدام خادم ويب محلي بسيط (مثل `Live Server` في VS Code) لتجنب مشاكل CORS عند تحميل الموارد أو إجراء طلبات AJAX في المستقبل.

## 4. كيفية تعديل الكود

يمكنك تعديل الكود باستخدام أي محرر نصوص أو بيئة تطوير متكاملة (IDE) مثل Visual Studio Code.

### 4.1. تعديل `index.html`

*   **هيكل الصفحة**: يمكنك إضافة أقسام جديدة (`<section>`) أو تعديل الأقسام الموجودة.
*   **الروابط**: تأكد من تحديث الروابط في قائمة التنقل (`<nav>`) لتعكس أي أقسام جديدة أو معدلة.
*   **ربط ملفات JavaScript/CSS**: تأكد من أن جميع ملفات JavaScript و CSS مربوطة بشكل صحيح في قسمي `<head>` و `<body>`.

### 4.2. تعديل `style.css`

*   **التصميم المرئي**: قم بتعديل الألوان، الخطوط، التباعد، وأي خصائص CSS أخرى لتغيير مظهر التطبيق.
*   **الاستجابة**: أضف استعلامات الوسائط (`@media queries`) لجعل التصميم متجاوباً مع مختلف أحجام الشاشات (الهواتف الذكية، الأجهزة اللوحية).

### 4.3. تعديل ملفات JavaScript (`auth.js`, `invoice.js`, `tables.js`, `products.js`, `app.js`)

*   **المنطق**: كل ملف JavaScript مسؤول عن جزء معين من وظائف النظام. يمكنك تعديل المنطق الحالي أو إضافة وظائف جديدة.
*   **التخزين**: حالياً، يتم استخدام `localStorage`. لتوصيل المشروع بقاعدة بيانات حقيقية، ستحتاج إلى:
    *   **خادم خلفي (Backend)**: بناء واجهة برمجة تطبيقات (API) باستخدام لغة مثل Node.js, Python (Flask/Django), PHP, أو Ruby on Rails.
    *   **طلبات AJAX**: استخدام `fetch` API أو `XMLHttpRequest` في JavaScript لإرسال واستقبال البيانات من الخادم الخلفي.
*   **التحقق من الصحة**: أضف المزيد من التحقق من صحة المدخلات (`input validation`) لضمان سلامة البيانات.

## 5. رفع المشروع على GitHub لضمان الاستدامة

يعد GitHub منصة ممتازة لاستضافة مشاريعك، تتبع التغييرات، والتعاون مع الآخرين. إليك الخطوات الأساسية لرفع هذا المشروع:

1.  **إنشاء حساب GitHub**: إذا لم يكن لديك حساب، قم بإنشاء واحد على [github.com](https://github.com/).
2.  **إنشاء مستودع جديد (Repository)**:
    *   بعد تسجيل الدخول، انقر على زر `+` في الزاوية العلوية اليمنى واختر `New repository`.
    *   أعط المستودع اسماً (مثال: `accounting-system`).
    *   اختر ما إذا كنت تريد المستودع `Public` (عام) أو `Private` (خاص).
    *   **لا** تقم بتهيئة المستودع بملف `README` أو `.gitignore` أو ترخيص في هذه المرحلة، لأن لديك بالفعل ملفات المشروع.
    *   انقر على `Create repository`.
3.  **تهيئة Git محلياً ورفع الملفات**: سيعرض لك GitHub بعد إنشاء المستودع تعليمات لرفع مشروع موجود. اتبع الخطوات التالية في سطر الأوامر (Terminal/Git Bash) داخل مجلد مشروعك (`accounting_system`):

    ```bash
    # تهيئة مستودع Git محلي
    git init

    # إضافة جميع ملفات المشروع إلى منطقة التجهيز (staging area)
    git add .

    # تسجيل التغييرات (commit) مع رسالة وصفية
    git commit -m "Initial commit: Setup basic accounting system structure"

    # تغيير اسم الفرع الرئيسي إلى main (اختياري، ولكن يفضل)
    git branch -M main

    # ربط المستودع المحلي بالمستودع البعيد على GitHub
    # تأكد من استبدال <YOUR_USERNAME> و <YOUR_REPOSITORY_NAME> بالقيم الصحيحة
    git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPOSITORY_NAME>.git

    # رفع الملفات إلى GitHub
    git push -u origin main
    ```

    قد يطلب منك Git إدخال اسم المستخدم وكلمة المرور الخاصة بك على GitHub. إذا كنت تستخدم المصادقة الثنائية، فقد تحتاج إلى إنشاء [رمز وصول شخصي (Personal Access Token)](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/creating-a-personal-access-token) واستخدامه ككلمة مرور.

4.  **GitHub Pages (للاستضافة المجانية)**:
    إذا كنت ترغب في استضافة هذا التطبيق البسيط مجاناً بحيث يمكن الوصول إليه عبر الإنترنت، يمكنك استخدام GitHub Pages:
    *   بعد رفع مشروعك إلى GitHub، اذهب إلى صفحة المستودع الخاص بك.
    *   انقر على `Settings` (الإعدادات).
    *   في الشريط الجانبي الأيسر، انقر على `Pages`.
    *   ضمن قسم `Branch`، اختر `main` (أو الفرع الذي يحتوي على ملفات مشروعك) ثم اختر مجلد `/(root)`.
    *   انقر على `Save`.
    *   بعد بضع دقائق، سيتم نشر موقعك وستحصل على رابط (عادةً يكون `https://<YOUR_USERNAME>.github.io/<YOUR_REPOSITORY_NAME>/`).

## 6. التطوير المستقبلي

لجعل هذا النظام أكثر قوة واستدامة، يوصى بالنظر في التحسينات التالية:

*   **قاعدة بيانات حقيقية**: استبدال `localStorage` بقاعدة بيانات مركزية.
*   **إطار عمل للواجهة الأمامية**: استخدام React, Vue, أو Angular لتطوير واجهة مستخدم أكثر تعقيداً وقابلية للصيانة.
*   **إطار عمل للخلفية**: استخدام Node.js (Express), Python (Django/Flask), أو PHP (Laravel) لبناء API قوي.
*   **نظام إدارة الحزم**: استخدام `npm` أو `yarn` لإدارة تبعيات JavaScript.
*   **اختبارات آلية**: كتابة اختبارات للوحدات والتكامل لضمان جودة الكود.
*   **التحكم في الإصدار**: الاستمرار في استخدام Git/GitHub لتتبع التغييرات والتعاون.

نأمل أن يكون هذا الدليل مفيداً لك في استخدام وتطوير هذا النظام المحاسبي. بالتوفيق!
