## 3) فصل المنيو العام عن الإدارة
- زر الإدارة (⚙️) أصبح **مخفيًا افتراضيًا** `display:none`، يظهر فقط عند `body.menu-admin`.

## 4) لوحة تحكم المنيو (Menu Dashboard)
- **نظرة عامة**: 5 بطاقات — الفئات(14)، الأصناف(103)، صور مؤكدة، **بدون صورة (99)**، تعديلات محفوظة، ومؤشر حالة **Draft/Local**.
- **جدول المنتجات**: صورة مصغرة، الاسم (عربي+إنجليزي)، الفئة، السعر، **شارة حالة الصورة**، الظهور، أزرار (إظهار/إخفاء، تعديل، 🖼 صورة، إزالة صورة).
- **بحث/تصفية** في الجدول عبر الفئة أو الاسم.
- **إضافة/تعديل**: حقول `n, en, d, de, p, category, origin, variant, image, visible`.
- **إدارة الصور**: رفع من الجهاز → تصغير Canvas إلى 512px → JPEG 0.82 → dataURL محلي (VERIFIED)؛ أو رابط خارجي (LINK — غير مؤكد بصريًا)؛ إزالة → تأكيد → `image:null` → **premium fallback**؛ الصنف نفسه لا يُحذف أبدًا.
- **الظهور**: `visible=false` يُخفي الصنف من المنيو العام فورًا مع بقائه في الجدول الإداري.
- **استعادة**: زر "استعادة الأساس" يمسح التعديلات المحلية فقط.

## 5) طبقة مستودع البيانات (Repository)
- `MenuRepository` و `LocalMenuRepository` (نفس التنفيذ):
  - `getProducts / createProduct / updateProduct / hideProduct / updateImage / removeImage / deleteCustomProduct / resetOverride / publish`

- `publish()` يعيد بصراحة `{ published:false, note: 'Local / Draft …' }` — أي تغييرات تظهر على هذا المتصفح فقط.

## 6) تصنيف صور المنتجات
| التصنيف | العدد | معناه |
|---|---|---|
| STRONG | 4 | صور مشفّرة يدويًا (V60، توست ميكس جبن، بيتزا مارجريتا، تشيز كيك) |
| VERIFIED | 0 (اختياري) | صورة يرفعها المالك عبر اللوحة (dataURL محلي) |
| UNVERIFIED | 12 | صور المالك الحقيقية في `OneDrive\Pictures` (V60، لاتيه، اسبيريسو دابل، …) — **النموذج لا يستطيع التأكد بصريًا**، لذا لم تُوصَّل ولن تُعرض |
| FALLBACK | 99 | أعلى الصورة الجليف سداسيّ (☕🍕…) + الحرف الأول — صادق، لا تخمين |
| MISLEADING | **0** | لا توجد أي صورة غير مطابقة |

قاعدة الجدول: مصادر الصور محصورة — override صريح ← كتالوج مُدقَّق STRONG ← رابط يضعه المالك؛ **ممنوع** اشتقاق صورة من الفئة أو اسم جزئي.
